## B. 決めていただくこと（5分・1件だけ）

### ⚠️ シーズンの開幕日をどうするか

**状況:** 各シーズンの開幕日を、**あえて空のままにしています。**

**理由:** 開幕日は「調べれば分かる事実」です。私の記憶で埋めると、**間違った年齢が全選手に表示されます。**
`docs/DECISIONS.md` §1 で「推測値で埋めない」と決めた通りにしてあります。
いまは開幕日が空のシーズンは**年齢を表示しません**（空欄になる）ので、誤った数字が出ることはありません。

**選択肢:**

| | 内容 | オーナーの手間 | 私の推奨 |
| --- | --- | --- | --- |
| **1** | 年齢表示を 10/4 では出さない | ゼロ | **◎ これを推します** |
| **2** | オーナーが出典を見て11シーズン分を入力 | 30分程度（管理画面 `W3-3` 完成後） | ○ |
| **3** | 公開後に API から取得する | ゼロ | ○ |

**推す理由:** 年齢は比較機能の中核ではありません。10/4 のゴールは「ファン1名が選手比較を操作する」ことなので、
ここに時間を使うより、比較そのものを良くする方が効きます。**2 と 3 は公開後でも足せます。**

**回答のしかた:** 「1で」とだけ言っていただければ十分です。

## C. 設計の中身（40分・読むだけ）

**気になったところだけ指摘してください。全部理解する必要はありません。**

### C-1. データの持ち方 → [SCHEMA.md](./SCHEMA.md)

21個の表と、**6つの設計判断**を日本語で説明してあります。要点だけ再掲します。

| | 判断 | ひとことで言うと |
| --- | --- | --- |
| ① | 率（FG%など）を保存せず、実数だけ保存する | 「1本も打っていない」と「0%」を区別するため |
| ② | チーム成績は公式値だけ。個人成績の合計で代用しない | 合計は公式記録と一致しないため |
| ③ | シーズン途中の移籍は分割して持つ | 移籍前後の成績を別々に出せるようにするため |
| ④ | 手動で直した値は元データを上書きせず別に持つ | 同期が走っても修正が消えないため |
| ⑤ | 年齢の基準日はシーズン開幕日 | → §B の話。他サイトと1歳ずれることがあります |
| ⑥ | 一部の表は外から読めなくしてある | 運用の記録・問い合わせ内容を守るため |

**⑤だけ補足します。** 他サイト（Basketball Reference など）は2月1日を基準にしているため、
**当サイトの年齢は他サイトと1歳ちがうことがあります。** これはオーナーが `DECISIONS.md` §1 で決めた通りです。
誤解を避けるため、**選手ページに基準日を明記します。**

### C-2. URLの形（後から変えると一番痛い箇所）

| ページ | URL |
| --- | --- |
| 選手一覧 | `/players` |
| 選手ページ | `/players/lebron-james` |
| 比較 | `/compare?p=選手&p=選手` |
| チーム | `/teams/lakers` |
| ある年のロスター | `/teams/lakers/2024-25` |
| ランキング | `/rankings` |

**確認していただきたい点:** この形で問題ないですか。
公開後に変えると、**共有されたリンクが切れ、検索結果からの流入も失います。**

補足を2つ:

- **比較ページは検索エンジンに載せません。** 選手の組み合わせは膨大で、中身の薄いページが
  大量に検索結果に並ぶとサイト全体の評価が下がるためです
- **コラムのメニューは作ってありますが、いまは隠してあります。** Q7 の決定通りです。
  公開後に出すときは1行変えるだけで出せます

### C-3. 品質をどう担保しているか

「動いています」と口で言うだけでは確かめようがないので、**機械が毎回チェックする形**にしてあります。

- **`main` に反映するたびに自動で検査**します。1つでも落ちたら赤く表示され、私が直します
- **数値の正しさは、答えの分かるデータを入れて確かめています。** たとえば
  「1本中1本成功のシーズン」と「100本中40本のシーズン」の通算成功率が、
  **70%（シーズン率の平均＝誤り）ではなく 40.6%（41÷101＝正解）になること**を毎回確認しています
- **制約は「宣言」ではなく「実際に壊れたデータを入れてみて弾かれること」で確認**しています

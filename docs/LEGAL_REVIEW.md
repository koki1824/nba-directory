## 3. 私が判断した点（違ったら直します）

- **お問い合わせはメールのみ。フォームは作っていません。**
  Q9 の決定どおりです。フォームを作ると送信内容をどこかに保存することになり、
  個人情報を預かる話が増えます。メールなら受信箱に届くだけで済みます

- **「権利・訂正」の窓口だけ強調しています。**
  権利に関する指摘は、確認できるまで表示を止める必要があり、埋もれさせられないためです

- **画像について「現在は掲載していない」と明記しました。**
  権利の確認が済んでいない画像を仮に置くことはしません。
  背番号・イニシャル・チームカラーによる代替表示を使います

- **非公式であることの文言を1か所に集約しました。**
  フッターと法務ページで言い回しが違うと、どれが正式な表明なのか分からなくなります。
  文言が全ページで一致していることをテストで見張っています

- **確認が済むまで各ページに「この文章は草案です」と出しています。**
  確認前の文章を「確認済みの規約」として読まれないようにするためです。
  ご承認いただいたら外します

1. **4項目の値**（運営者名 / メールアドレス / 施行日 / 所在地は任意）
2. **7ページの内容** — OK / 直してほしい箇所
3. **アクセス解析や広告を入れる予定があるか** — あればプライバシーポリシーに追記します

いただいたら、値を入れて「草案」の表示を外します。
